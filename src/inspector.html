StreamHub connection

Use ADD STREAMHUB and NEXT HUB on your XL to manage units in this panel.

REST API: HTTP port 8893 or HTTPS port 8896. For HTTPS, enter https:// followed by the server address. Web login and previews use separate ports: HTTP 8888 or HTTPS 443. Web access enables previews and device recording status. Your password is used to sign in and is not saved. Address, API key, username and preview token are stored locally. Disconnect forgets all access details for this unit. Delete StreamHub removes the saved unit.

This changes the browser shortcut only. Preview access is configured separately below.
Advanced Leave empty to follow the StreamHub address. If an override is unreachable, the plugin also tries the web interface on the configured StreamHub host.
