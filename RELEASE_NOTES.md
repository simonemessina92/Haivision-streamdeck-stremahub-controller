# v0.13.0 — Golden release

Complete standalone 32-key Stream Deck XL controller for Haivision StreamHub.

- Inputs, SDI/ST2110, NDI and IP outputs, encoders and Mojo Pro controls.
- Input/output previews, routing, recording, intercom and video return.
- Bulk controls, clipboard links and live error/warning indicators.
- Saved StreamHubs with ADD STREAMHUB and NEXT HUB in one panel.
- Disconnect forgets selected access details; login passwords are not saved.
- English interface and project identity without personal names.

Validated with 100 automated tests and Elgato plugin validation. Windows XL reconnection after a PC restart was verified by the user.

Download the ZIP, extract it, install the .streamDeckPlugin and select the supplied StreamHub XL profile. Configure from the top-right ONLINE / OFFLINE key in the Stream Deck app.
